# ReplyMentor Web

Frontend do ReplyMentor: Plataforma de assistência inteligente que utiliza IA generativa (LLMs), processamento de áudio e integração com APIs para analisar conversas, gerar respostas contextualizadas e apoiar interações profissionais.

## Contexto do Projeto

- README raiz: `../README.md`
- Documentacao funcional/tecnica: `../doc-reply-mentor/README.md`

## Stack

- Next.js 16
- React 19
- TypeScript
- Zustand
- TanStack Query

## Execucao Local

```bash
npm install
npm run dev
```

Aplicacao em: `http://localhost:3000`

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Integracao com Backend

Este app consome a API do diretório `../replymentor-backend`.
